# Детальная статистика и графики профессионализма

## 📊 Обзор

Добавлена полная система визуализации прогресса студентов с интерактивными графиками и детальной аналитикой изменений навыков во времени.

---

## 🎯 Новые компоненты

### 1. ProficiencyTrendChart
**Файл:** `src/features/teacher/components/charts/ProficiencyTrendChart.tsx`

**Что отображает:**
- Линейный график изменения баллов профессионализма за последние 30 дней
- Каждая точка цветом показывает уровень (желтый/синий/зеленый)
- В tooltip видна причина изменения (автоматический расчет/ручная установка/входной тест)

**Использование:**
```tsx
<ProficiencyTrendChart
  studentId="uuid"
  daysBack={30}
  height={300}
/>
```

**Особенности:**
- Цветные точки по уровню (beginner/intermediate/advanced)
- Градиентная заливка под линией
- Детальные tooltips с причинами изменений
- Легенда уровней внизу графика

### 3. PeriodComparisonCard
**Файл:** `src/features/teacher/components/PeriodComparisonCard.tsx`

**Что отображает:**
- Сравнение двух периодов времени (по умолчанию 7 дней)
- Средний балл, уровень, количество решений
- Процент улучшения/снижения
- Визуальные индикаторы трендов (📈/📉/➡️)

**Использование:**
```tsx
<PeriodComparisonCard
  studentId="uuid"
  currentPeriodDays={7}
  previousPeriodDays={7}
/>
```

**Критерии трендов:**
- **Улучшение** (зеленый): > +5%
- **Снижение** (красный): < -5%
- **Стабильно** (серый): от -5% до +5%

**Insights:**
- Предупреждение, если студент не решал задачи
- Поздравление при улучшении
- Предупреждение при снижении

## 🔧 API Функции

**Файл:** `src/features/teacher/api/proficiencyTrendsApi.ts`

### `getProficiencyTrend(studentId, daysBack)`
Получает историю изменений профессионализма за период.

**Возвращает:**
```typescript
interface ProficiencyTrendPoint {
  date: string;
  score: number;
  level: ProficiencyLevel;
  reason: string;
}
```

### `getSkillsSnapshot(studentId)`
Получает текущий снимок всех 12 навыков.

**Возвращает:**
```typescript
Record<string, number> // skill_name → proficiency_percentage
```

### `comparePeriods(studentId, currentPeriodDays, previousPeriodDays)`
Сравнивает два периода времени.

**Возвращает:**
```typescript
{
  current: ComparisonPeriod;
  previous: ComparisonPeriod;
  improvement_percentage: number;
}
```

### `getSkillChanges(studentId, daysBack)`
Получает изменения навыков за период.

**Возвращает:**
```typescript
interface SkillSnapshot {
  skill_name: string;
  skill_display_name: string;
  current_proficiency: number;
  previous_proficiency: number;
  change: number;
  trend: 'improving' | 'declining' | 'stable';
}
```

### StudentDetailsPage
**Путь:** `/teacher/students/:id`

**Расположение:**

2. Текущий уровень владения
3. **НОВОЕ:** Сравнение периодов + Изменения навыков (2 карточки)
4. **НОВОЕ:** График истории профессионализма
5. **НОВОЕ:** Радарная диаграмма навыков
6. Информация о профиле

**Условия отображения:**
- Графики показываются только если есть proficiencyOverview
- Если нет данных за период - показывается соответствующее сообщение

## 📊 Примеры использования

### Пример 1: Анализ прогресса студента

**Сценарий:** Учитель хочет увидеть, как менялся уровень студента за последний месяц.

**Действия:**
1. Откройте `/teacher/students/:id`
2. Прокрутите до секции "📈 История изменения профессионализма"
3. График покажет все изменения за 30 дней
4. Кликните на любую точку для деталей

**Что увидим:**
- Дату и время изменения
- Старый и новый балл
- Уровень (beginner/intermediate/advanced)
- Причину (автоматический расчет/ручная установка/тест)

---

### Пример 2: Определение слабых навыков

**Сценарий:** Нужно понять, по каким навыкам студент отстает.

**Действия:**
1. Откройте `/teacher/students/:id`
2. Прокрутите до секции "🎯 Профиль навыков (Radar Chart)"
3. Посмотрите на радарную диаграмму
4. Слабейшие 3 навыка выделены под графиком

**Что увидим:**
- Визуальное сравнение всех 12 навыков
- Топ-3 слабых навыков с процентами
- Цветовую индикацию (красный/оранжевый/желтый)

**Следующие шаги:**
- Назначьте задания, фокусирующиеся на слабых навыках
- Используйте персонализированные рекомендации

---

### Пример 3: Мониторинг еженедельного прогресса

**Сценарий:** Проверить, улучшился ли студент за последнюю неделю.

**Действия:**
1. Откройте `/teacher/students/:id`
2. Посмотрите на карточку "Сравнение периодов"
3. Проверьте процент улучшения

**Что увидим:**
- Средний балл: предыдущие 7 дней vs текущие 7 дней
- Изменение уровня (если было)
- Количество решенных задач
- Процент улучшения/снижения

**Insights:**
- 📈 Зеленая карточка: улучшение > 5%
- 📉 Красная карточка: снижение > 5%
- ➡️ Серая карточка: изменение < 5%

---

### Пример 4: Детальный анализ изменений навыков

**Сценарий:** Понять, какие конкретно навыки улучшились/снизились.

**Действия:**
1. Откройте `/teacher/students/:id`
2. Посмотрите на карточку "Изменения навыков"
3. Изучите список улучшившихся/снизившихся

**Что увидим:**
- Счетчики: X улучшились, Y стабильно, Z снизились
- Список улучшившихся навыков (зеленый)
- Список снизившихся навыков (красный)
- Сворачиваемый список стабильных навыков

**Действия:**
- Похвалить за улучшения
- Назначить практику для снизившихся навыков

## 🐛 Troubleshooting

### График не загружается
**Проблема:** Spinner крутится бесконечно

**Решение:**
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что `proficiency_history` содержит записи
3. Проверьте, что student_id правильный

### Радар показывает все 0%
**Проблема:** Все навыки на 0%

**Решение:**
1. Студент еще не решал задачи
2. Проверьте `user_skill_profile` на наличие записей
3. Убедитесь, что триггеры работают

### Сравнение периодов показывает 0% изменение
**Проблема:** Нет данных за период

**Решение:**
1. Студент не решал задачи в этот период
2. Уменьшите период (например, с 7 до 3 дней)
3. Проверьте `proficiency_history` за эти даты
