# 🤖 AI Генератор заданий

## Обзор

AI Генератор заданий - это мощный инструмент для учителей, который позволяет создавать программистские задания с помощью искусственного интеллекта. Вместо того чтобы вручную писать описание, тесты и подсказки, учитель может просто указать тему, и AI сгенерирует готовые задания.

## Возможности

### Что AI создает автоматически:

✅ **Название задания** - привлекательное для детей 10-16 лет
✅ **Описание задачи** - понятное объяснение что нужно сделать
✅ **Тестовые случаи** - минимум 3 теста с входными данными и ожидаемым выводом
✅ **Подсказки** - 2-3 подсказки, которые направляют, но не дают готовое решение
✅ **Эталонное решение** - корректный код на выбранном языке
✅ **Целевые навыки** - список навыков, которые развивает задание

### Настройки:

- **Тема** - о чем будет задание (например: "Циклы for", "Работа со строками")
- **Сложность** - easy (легко), medium (средне), hard (сложно)
- **Язык программирования** - Python, JavaScript, Java, C++
- **Количество** - от 1 до 5 заданий за раз
- **Дополнительный контекст** - любые дополнительные требования

## Как использовать

### Шаг 1: Развертывание Edge Function

Перед первым использованием нужно развернуть Edge Function:

```bash
# Убедитесь что GROQ_API_KEY добавлен в Supabase Dashboard
./scripts/deploy-generate-level.sh
```

### Шаг 2: Генерация заданий

1. Откройте **Teacher Dashboard** → **Levels** → **Manage Levels**
2. Нажмите кнопку **"🤖 AI Генератор"**
3. Заполните форму:
   - **Тема**: "Работа со списками в Python"
   - **Сложность**: Medium
   - **Язык**: Python
   - **Количество**: 3
   - **Контекст** (опционально): "Задания должны использовать методы списков"
4. Нажмите **"✨ Сгенерировать задания"**
5. Подождите 5-10 секунд пока AI создает задания

### Шаг 3: Проверка и выбор

1. AI покажет превью всех сгенерированных заданий
2. Каждое задание показывает:
   - Название и сложность
   - Краткое описание
   - Количество тестов, подсказок, навыков
3. Выберите задания которые хотите сохранить (по умолчанию выбраны все)
4. Можете убрать галочки с ненужных заданий

### Шаг 4: Сохранение

- Нажмите **"✓ Одобрить и сохранить (N)"** - сохранит выбранные задания
- Или нажмите **"🔄 Сгенерировать заново"** - создаст новые варианты

```

    ↓

    ↓

    ↓

    ↓
```

## Лучшие практики

### ✅ Хорошие темы

- "Циклы while"
- "Функции и параметры"
- "Работа со списками"
- "Условные операторы"
- "Рекурсия простые примеры"

### ❌ Плохие темы

- "Программирование" (слишком общее)
- "Сделай сложную задачу" (неконкретно)
- "Hello World" (слишком простое для генерации)

### Советы:

1. **Будьте конкретны** - чем точнее тема, тем лучше результат
2. **Используйте контекст** - укажите специфические требования
3. **Проверяйте решения** - всегда тестируйте сгенерированный код
4. **Редактируйте** - можно сохранить задание и потом отредактировать вручную
5. **Экспериментируйте** - если результат не понравился, сгенерируйте заново

## Безопасность

- ✅ API ключ хранится в Supabase secrets (не в коде)
- ✅ Только учителя могут генерировать задания (проверка роли)
- ✅ Валидация входных данных на стороне Edge Function
- ✅ Ограничение количества заданий (защита от злоупотребления)

## Стоимость

### Groq API (бесплатный tier):
- 14,400 запросов/день
- 6,000-15,000 токенов/минуту
- 1 генерация ≈ 1000-2000 токенов
- **Итого**: ~300-400 генераций в день бесплатно

### Рекомендации:
- Для школы из 10 учителей это более чем достаточно
- Генерируйте несколько заданий сразу (эффективнее)
- Если нужно больше - подключите платный план Groq ($0.10 за 1M токенов)

## Решение проблем

### "Edge Function error"
**Причина**: Edge Function не развернута
**Решение**: Запустите `./scripts/deploy-generate-level.sh`

### "GROQ_API_KEY is not set"
**Причина**: API ключ не добавлен в Supabase
**Решение**: Dashboard → Settings → Edge Functions → Secrets → Add GROQ_API_KEY

### "Failed to parse generated levels"
**Причина**: AI вернул невалидный JSON
**Решение**: Попробуйте сгенерировать заново с более конкретной темой

### "Timeout"
**Причина**: Слишком долгая генерация
**Решение**: Уменьшите количество заданий или упростите тему
