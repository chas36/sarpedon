### 2. Компоненты

#### **ProficiencyOverviewCard**
**Файл:** `src/features/teacher/components/ProficiencyOverviewCard.tsx`

**Отображает:**

- Процентное соотношение

- Цветовая индикация (желтый/синий/зеленый)

#### **StudentsNeedingHelpCard**
**Файл:** `src/features/teacher/components/StudentsNeedingHelpCard.tsx`

**Отображает:**
- Топ-10 студентов, нуждающихся в помощи
- Критерии включения:
  - Beginner < 35 баллов
  - Intermediate < 50 баллов
  - Advanced < 65 баллов
  - Не проходил оценку
  - Давно не практиковался (> 7 дней) и балл < 40
- Причину включения в список
- Приоритет (красный/оранжевый/желтый индикатор)
- Прямой переход к профилю студента

## 📊 Критерии "Нуждается в помощи"

| Уровень | Критерий |
|---------|----------|
| Beginner | Балл < 35/100 |
| Intermediate | Балл < 50/100 |
| Advanced | Балл < 65/100 |
| Любой | Не проходил оценку |
| Любой | Давно не практиковался (> 7 дней) И балл < 40 |

## 🎨 Визуальная концепция

### Цветовая схема:
- 🟢 **Зеленый** - Продвинутый / Все хорошо
- 🔵 **Синий** - Средний уровень
- 🟡 **Желтый** - Начинающий
- 🔴 **Красный** - Нуждается в помощи / Критично

### Индикаторы приоритета:
- 🔴 **Красный круг** - Критично (балл < 30)
- 🟠 **Оранжевый круг** - Срочно (балл < 50)
- 🟡 **Желтый круг** - Требует внимания (балл < 65)

## 🚀 Как использовать

### Для учителей:

1. **Ежедневная проверка:**
   - Откройте `/teacher/proficiency-analytics`
   - Проверьте карточку "Студенты, нуждающиеся в помощи"
   - Работайте с 2-3 студентами из списка

2. **Фильтрация студентов:**
   - Откройте `/teacher/students`
   - Используйте фильтры для группировки
   - Включите "⚠️ Нужна помощь" для приоритизации

3. **Индивидуальная работа:**
   - Кликните на студента в любой карточке
   - Просмотрите weak_areas
   - Назначьте персонализированные задания

### Для разработчиков:

**Компоненты:**
```typescript
import { ProficiencyOverviewCard } from '@/features/teacher/components/ProficiencyOverviewCard';
import { StudentsNeedingHelpCard } from '@/features/teacher/components/StudentsNeedingHelpCard';

// Использование
<ProficiencyOverviewCard className="10A" />
<StudentsNeedingHelpCard className="10A" limit={10} />
```

**API:**
```typescript
import {
  getClassProficiencyStats,
  getAllStudentsWithProficiency
} from '@/features/teacher/api/proficiencyApi';

// Получить статистику
const stats = await getClassProficiencyStats('10A');
// { total_students, beginner_count, intermediate_count, advanced_count, average_score }

// Получить всех студентов
const students = await getAllStudentsWithProficiency();
// [{ id, first_name, last_name, proficiency_level, proficiency_score, ... }]
```
