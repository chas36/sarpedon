# Улучшения интерфейса страницы решения задач

## Проблема

Предыдущий дизайн имел следующие недостатки:

1. **AI Наставник внизу страницы** - дети его не видели и не использовали
2. **Нет навигации к следующему уровню** - нужно было возвращаться к списку
3. **Вертикальный layout** - много скроллинга
4. **Не оптимизирован для детей** - слишком технический

## Решение

### Новый двухколоночный layout

```
┌──────────────────────────────────────────────────────────────────┐
│  [Название уровня]                           [← Все уровни]      │
├──────────────────────────────────┬───────────────────────────────┤
│                                  │                               │
│  📝 Описание задачи             │  🎉 УСПЕХ!                    │
│  Текст задания...               │  Все тесты пройдены!          │
│                                  │  [Следующее задание →]        │
│                                  │                               │
├──────────────────────────────────┤  🤖 AI Наставник              │
│  💻 Твое решение                │  Твой помощник                │
│  ┌────────────────────────────┐ │                               │
│  │ Monaco Editor              │ │  Подсказки и советы...        │
│  │ ...code...                 │ │                               │
│  │                            │ │                               │
│  └────────────────────────────┘ │                               │
├──────────────────────────────────┤                               │
│  [▶️ Запустить]  [💾 Сохранить]│                               │
├──────────────────────────────────┤                               │
│  📊 Результаты выполнения       │  💭 Подсказки к заданию       │
│  ✓ Тест 1                       │  1. Используй цикл...         │
│  ✗ Тест 2                       │  2. Не забудь про...          │
│                                  │                               │
└──────────────────────────────────┴───────────────────────────────┘
```

### Основные изменения

#### 1. **Двухколоночный layout**
- **Левая колонка (2/3 ширины)**: Основной контент
  - Описание задачи
  - Редактор кода
  - Результаты выполнения
- **Правая колонка (1/3 ширины)**: Помощники
  - Блок успеха с кнопкой "Следующее задание"
  - AI Наставник (всегда видим!)
  - Подсказки к заданию

#### 2. **AI Наставник в сайдбаре**
✅ **Всегда виден** - дети не пропустят помощь
✅ **Дружелюбный дизайн** - градиент, эмодзи 🤖
✅ **Три состояния**:
- Idle: "Запусти код, и я помогу тебе!"
- Ошибка: Показывает feedback и подсказки
- Успех: "Отличная работа! 🌟"

#### 3. **Навигация к следующему уровню**
```typescript
// Новая API функция
export async function getNextLevel(currentLevelId: string): Promise<Level | null>
```

При успешном выполнении:
```
┌─────────────────────────────┐
│  🎉                         │
│  Отлично!                   │
│  Все тесты пройдены!        │
│                             │
│  [Следующее задание →]      │
└─────────────────────────────┘
```

#### 4. **UX улучшения для детей**

**Эмодзи и визуальные индикаторы:**
- 📝 Описание задачи
- 💻 Твое решение
- ▶️ Запустить код
- 💾 Сохранить
- 🤖 AI Наставник
- 💡 Подсказки
- 🎉 Успех
- ✓/✗ Результаты тестов

**Цветовое кодирование:**
- Зеленый: Успех, пройденные тесты
- Красный: Ошибки, непройденные тесты
- Синий/Фиолетовый: AI помощник
- Желтый: Предупреждения

**Упрощенная терминология:**
- "Твое решение" вместо "Code Editor"
- "Запустить код" вместо "Execute"
- "Следующее задание" вместо "Next Level"

## Преимущества

### Для студентов
✅ AI помощник всегда на виду
✅ Понятная навигация между уровнями
✅ Меньше скроллинга
✅ Визуально привлекательный интерфейс
✅ Мгновенная обратная связь

### Для учителей
✅ Студенты используют AI подсказки (видны)
✅ Лучший flow обучения (меньше застреваний)
✅ Автоматическая прогрессия через уровни

### Для платформы
✅ Выше engagement
✅ Меньше фрустрации
✅ Больше завершенных уровней
