# Учительская аналитическая панель

## 📊 Обзор

Новая аналитическая панель для учителей предоставляет подробную информацию об уровне владения программированием студентов и позволяет быстро выявлять тех, кому требуется дополнительная помощь.

---

## 🚀 Как пользоваться

### 1. Главная страница аналитики

**Путь:** `/teacher/proficiency-analytics`
**Навигация:** Ученики → 📊 Аналитика

#### Что отображается:

##### **Распределение по уровням владения**
- Визуальное представление количества студентов на каждом уровне
- 3 категории:
  - **Начинающий** (0-40 баллов) - желтый цвет
  - **Средний** (41-70 баллов) - синий цвет
  - **Продвинутый** (71-100 баллов) - зеленый цвет
- Средний балл по всем студентам
- Процентное соотношение
- Интерактивная диаграмма

##### **Студенты, нуждающиеся в помощи**
- Список до 10 студентов с низкими показателями
- Критерии включения:
  - Начинающий с баллом < 35
  - Средний с баллом < 50
  - Продвинутый с баллом < 65
  - Не проходил оценку
  - Давно не практиковался (> 7 дней) и балл < 40

##### **Быстрые действия**
- Переход к списку всех студентов
- Переход к общей статистике
- Переход к управлению заданиями

##### **Информационные блоки**
- Советы по помощи студентам
- Критерии уровней владения

---

### 2. Улучшенная страница студентов

**Путь:** `/teacher/students`

#### Новые фильтры:

##### **Класс** (существующий, без изменений)
- Фильтрация по классу
- Опция "Все классы"

##### **Уровень владения** (новый)
- Все уровни
- Начинающий
- Средний
- Продвинутый

##### **Сортировка** (новая)
- По имени (по умолчанию)
- По баллам (↓) - от высших к низшим
- По баллам (↑) - от низших к высшим
- По классу

##### **Фильтр "Нуждаются в помощи"** (новый)
- Кнопка-переключатель красного цвета
- Показывает только студентов, требующих внимания
- Использует те же критерии, что и карточка на главной странице

##### **Кнопка "Сбросить"**
- Сбрасывает все фильтры к значениям по умолчанию

#### Новая статистика:

- **Всего студентов** - общее количество
- **После фильтрации** - количество после применения фильтров
- **Классов** - количество классов
- **Нуждаются в помощи** - количество студентов с низкими показателями (красный цвет)

#### Таблица студентов:

##### **Новая колонка "Статус"**
- ✓ (зеленый) - студент в порядке
- ! (красный) - студент нуждается в помощи

##### **Визуальные индикаторы**
- Строки студентов, нуждающихся в помощи, имеют легкий красный фон
- Баллы студентов, нуждающихся в помощи, выделены красным цветом

##### **Колонка "Уровень владения"**
- Цветной бейдж с уровнем
- Балл в формате X/100

---

## 🎯 Критерии "Нуждается в помощи"

Студент автоматически попадает в список "Нуждающихся в помощи", если выполняется хотя бы одно из условий:

| Уровень | Критерий |
|---------|----------|
| **Начинающий** | Балл < 35/100 |
| **Средний** | Балл < 50/100 |
| **Продвинутый** | Балл < 65/100 |
| **Любой** | Не проходил оценку (профессионализм не определен) |
| **Любой** | Давно не практиковался (> 7 дней) И балл < 40 |

## 💡 Рекомендации по работе с аналитикой

### Ежедневная работа:

1. **Утренняя проверка:**
   - Откройте "📊 Аналитика"
   - Проверьте карточку "Студенты, нуждающиеся в помощи"
   - Кликните на студента для перехода к его профилю

2. **Планирование занятий:**
   - Используйте фильтр "Уровень владения" для группировки
   - Назначайте задания в соответствии с уровнем
   - Проверяйте weak_areas студентов в их профилях

3. **Индивидуальная работа:**
   - Включите фильтр "⚠️ Нужна помощь" на странице студентов
   - Отсортируйте по баллам (↑) для приоритизации
   - Работайте сначала с теми, у кого самые низкие баллы

### Еженедельная аналитика:

1. **Мониторинг прогресса:**
   - Проверяйте изменения в распределении по уровням
   - Отслеживайте средний балл класса
   - Сравнивайте количество студентов, нуждающихся в помощи

2. **Корректировка программы:**
   - Если много студентов на уровне "Начинающий" - упростите задания
   - Если много на уровне "Продвинутый" - добавьте сложные задачи
   - Балансируйте сложность заданий

### Работа с отдельными студентами:

1. **Кликните на студента** в любой карточке
2. **В профиле студента:**
   - Проверьте историю изменений профессионализма
   - Посмотрите weak_areas (слабые навыки)
   - Назначьте персонализированные задания
   - При необходимости установите уровень вручную

## 🔧 Технические детали

### API функции:

- `getClassProficiencyStats(className?)` - статистика по классу
- `getAllStudentsWithProficiency()` - список всех студентов с proficiency
- `getStudentWeakAreas(studentId, limit)` - слабые навыки студента
- `getStudentProficiencyHistory(studentId)` - история изменений

### Компоненты:

- `ProficiencyOverviewCard` - распределение по уровням
- `StudentsNeedingHelpCard` - студенты, нуждающиеся в помощи
- `ProficiencyDashboardPage` - главная страница аналитики
- `StudentsPage` (enhanced) - улучшенная страница студентов

### Маршруты:

- `/teacher/proficiency-analytics` - главная страница аналитики
- `/teacher/students` - страница студентов (с новыми фильтрами)
- `/teacher/students/:id` - детальный профиль студента

## 📈 Примеры использования

### Пример 1: Найти всех начинающих студентов для группового занятия

1. Откройте `/teacher/students`
2. Выберите фильтр "Уровень" → "Начинающий"
3. Выберите фильтр "Класс" → нужный класс
4. Отсортируйте "По баллам (↑)"
5. Работайте с группой по общим weak_areas

### Пример 2: Экстренная помощь студентам с критическими показателями

1. Откройте `/teacher/students`
2. Включите фильтр "⚠️ Нужна помощь"
3. Отсортируйте "По баллам (↑)"
4. Первые 3-5 студентов требуют немедленного внимания
5. Кликните на каждого → проверьте weak_areas → назначьте задания

### Пример 3: Мониторинг прогресса класса

1. Откройте `/teacher/proficiency-analytics`
2. Выберите класс в фильтре
3. Проверьте распределение:
   - Цель: 20% Beginner, 50% Intermediate, 30% Advanced
   - Если распределение не соответствует - корректируйте программу
4. Проверьте средний балл (цель: > 50)

## 🔄 Автоматическое обновление

Система автоматически:
- Пересчитывает proficiency после каждого решения задачи
- Обновляет weak_areas на основе ошибок
- Сохраняет историю изменений
- Отслеживает дату последней оценки

Учитель может:
- Вручную установить уровень студента (кнопка в профиле)
- Включить/выключить автоматический расчет
- Просматривать историю всех изменений
