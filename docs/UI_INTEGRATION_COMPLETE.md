## 🚀 Как запустить и протестировать:

### 1. Установите зависимости (если еще не сделано):
```bash
npm install
```

### 2. Запустите dev сервер:
```bash
npm run dev
```

### 3. Откройте браузер:
```
http://localhost:5173
```

### 4. Протестируйте как студент:
1. Войдите как студент
2. Перейдите на страницу **"Прогресс"**
3. Вы увидите:
   - Карточку с вашим уровнем (Beginner/Intermediate/Advanced)
   - Карточку с прогрессом по 12 навыкам
   - Если навыков пока нет - увидите приглашение начать решать задачи

### 5. Протестируйте как учитель:
1. Войдите как учитель
2. Перейдите в **"Ученики"**
3. Откройте профиль любого студента
4. Вы увидите:
   - Бейдж с уровнем студента
   - Детальный профиль навыков
   - Историю изменений уровня
   - Кнопки для управления уровнем

## 📊 Как работает автоматически:

1. **Студент решает задачу** → Отправляет код
2. **База данных автоматически:**
   - Обновляет proficiency_level (beginner/intermediate/advanced)
   - Обновляет proficiency_score (0-100)
   - Обновляет user_skill_profile для каждого навыка
   - Записывает в proficiency_history
3. **UI автоматически отображает** свежие данные при загрузке страницы

**Никаких ручных действий не требуется!** Всё работает через триггеры БД.

## 🎨 Компоненты и API:

### Shared компоненты:
```typescript
import { ProficiencyBadge } from '@/shared/components/ui';

<ProficiencyBadge
  level="intermediate"
  score={65}
  showScore={true}
  size="md"
/>
```

### API для студентов:
```typescript
import { getStudentProficiency, getStudentSkills } from '@/shared/api/proficiencyApi';

const proficiency = await getStudentProficiency(studentId);
const skills = await getStudentSkills(studentId);
```

### API для учителей:
```typescript
import {
  setStudentProficiency,
  getAllStudentsWithProficiency
} from '@/features/teacher/api/proficiencyApi';

// Установить уровень вручную
await setStudentProficiency(studentId, 'intermediate', 65, 'Отличный прогресс');

// Получить всех студентов с уровнями
const students = await getAllStudentsWithProficiency();
```
