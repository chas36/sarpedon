# Changelog

All notable changes to Sarpedon will be documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-06-13

### Added

- Browser-based programming exercises with Monaco Editor and automated checks.
- Student progress tracking, submissions, skills, and learning history.
- Teacher workflows for students, classes, levels, lessons, and analytics.
- Role-based student, teacher, editor, and classroom display interfaces.
- Supabase authentication, PostgreSQL migrations, Realtime, and RLS policies.
- Optional AI feedback and AI-assisted exercise generation through Edge
  Functions.
- Automated tests for critical application modules and shared components.
- English and Russian project documentation.
- MIT License.

### Notes

This is the first public open-source release. Some features remain experimental,
and deployments should review all database migrations and security policies
before processing real student data.
