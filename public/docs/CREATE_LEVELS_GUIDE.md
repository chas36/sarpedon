# Руководство по созданию заданий (для учеников без доступа к системе)

## Как создавать задания?

Если у вас нет доступа к системе, вы можете составить задания в формате JSON и отправить учителю для импорта.

## Шаг 1: Скопируйте шаблон

Используйте файл `level-template.json` как основу. Вы можете редактировать его в любом текстовом редакторе (Notepad++, VS Code, Sublime Text и т.д.)

## Шаг 2: Заполните поля

### Обязательные поля:

- **title** (строка) - Название задания
- **description** (строка) - Подробное описание задания
- **language** (строка) - Язык программирования: `"python"`, `"javascript"`, `"java"`, `"cpp"`, `"csharp"`
- **difficulty** (число) - Сложность от 1 до 10
  - 1-3: Легко
  - 4-7: Средне
  - 8-10: Сложно
- **reference_solution** (строка) - Эталонное решение (должно работать!)
- **test_cases** (массив) - Минимум 1 тест-кейс
  - `input` (строка) - Входные данные
  - `output` (строка) - Ожидаемый результат
  - `description` (строка, опционально) - Описание теста

### Опциональные поля:

- **educational_context** (строка) - Образовательный контекст
- **topic** (строка) - Тема задания (например, "Циклы", "Рекурсия")
- **target_skills** (массив строк) - Навыки, которые развивает задание
- **hints** (массив строк) - Подсказки для студентов

## Шаг 3: Проверьте формат

Убедитесь, что:
1. ✅ JSON валидный (можно проверить на jsonlint.com)
2. ✅ Все строки в двойных кавычках
3. ✅ Эталонное решение работает
4. ✅ Все тест-кейсы проходят с эталонным решением
5. ✅ Есть хотя бы один тест-кейс

## Шаг 4: Сохраните и отправьте

Сохраните файл с расширением `.json` и отправьте учителю. Учитель импортирует задания через интерфейс модерации.

## Пример полного задания:

```json
[
  {
    "title": "Сумма чисел от 1 до N",
    "description": "Напишите программу, которая вычисляет сумму всех чисел от 1 до N включительно.",
    "educational_context": "Изучение циклов и базовых арифметических операций",
    "language": "python",
    "difficulty": 2,
    "topic": "Циклы",
    "target_skills": ["Циклы for", "Базовая арифметика", "Ввод-вывод"],
    "reference_solution": "n = int(input())\nresult = sum(range(1, n + 1))\nprint(result)",
    "test_cases": [
      {
        "input": "5",
        "output": "15",
        "description": "Базовый тест: 1+2+3+4+5=15"
      },
      {
        "input": "1",
        "output": "1",
        "description": "Граничный случай: N=1"
      },
      {
        "input": "10",
        "output": "55",
        "description": "Средний тест: 1+2+...+10=55"
      }
    ],
    "hints": [
      "Используйте цикл for для перебора чисел от 1 до N",
      "Не забудьте про функцию sum() или переменную-накопитель",
      "В Python есть функция range(start, stop) для генерации последовательности"
    ]
  }
]
```

## Советы:

1. 💡 **Начните с простого** - сначала создайте 1-2 задания, чтобы освоиться с форматом
2. 🧪 **Протестируйте решение** - убедитесь, что эталонное решение действительно работает
3. 📝 **Пишите понятно** - описание должно быть четким и понятным для других студентов
4. ✨ **Разнообразие тестов** - добавьте базовые тесты, граничные случаи, сложные примеры
5. 🎯 **Подсказки по порядку** - первая подсказка самая общая, последняя - почти готовое решение

## Частые ошибки:

❌ **Неправильно:**
```json
{
  "title": 'Задание',  // Одинарные кавычки
  "difficulty": "5",   // Строка вместо числа
  "test_cases": [
    {
      "input": "test"    // Нет output
    }
  ],
}  // Лишняя запятая в конце
```

✅ **Правильно:**
```json
{
  "title": "Задание",
  "difficulty": 5,
  "test_cases": [
    {
      "input": "test",
      "output": "expected"
    }
  ]
}
```
